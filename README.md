# SmartSpend 

SmartSpend AI is a smart financial management application that helps users
track expenses, manage budgets, monitor savings goals, and receive
personalized financial insights.

## 🚀 Features

- 🔐 User Registration and Login
- 🔑 JWT-based Authentication
- 💳 Add, Edit and Delete Expenses
- 📊 Dashboard with Financial Overview
- 💰 Monthly Budget Management
- 🏷️ Category-wise Budget Tracking
- 🔔 Budget Notifications and Alerts
- 🎯 Savings Goal Tracking
- 🤖 AI Financial Guardian
- 📈 Monthly Expense Forecast
- 📋 Transaction History
- 🔎 Search, Filter and Sort Transactions
- 📱 Responsive User Interface
- 🚪 Secure Logout
